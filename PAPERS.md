# Source Corpus — Bibliography Manifest

This repository does not redistribute the full text of the 67 research papers used to build the retrieval corpus, to avoid republishing copyrighted journal content. Citation metadata below was extracted from each PDF's own title page and cross-checked against the CrossRef public API (https://api.crossref.org) by title similarity; it was **not** manually verified against each publisher's own record, so treat DOIs/years as a strong starting point, not a guarantee.

**To reproduce the corpus:** source each paper yourself (library access, publisher site, or an open-access copy) and save it as a PDF under `Data/`. `DocumentRetriever.py` only needs the folder to contain PDF files -- exact filenames don't matter.

Confidence key: **High** = automated title match ≥ 0.70 (or manually confirmed). **Medium** = 0.40–0.70, plausible but not independently confirmed — check before citing. **Unresolved** = no reliable CrossRef match found; cite from your own records.
